## 4. Реалізація

В `src/notify.py` заглушку замінено реалізацією SMTP через стандартну бібліотеку Python. Параметри SMTP читаються зі змінних середовища. Встановлено timeout, використовується STARTTLS із SSL-контекстом. `send_email()` повертає `False` при помилці SMTP або порожній адресі. `notify_user()` повертає результат доставки, а `bulk_notify()` рахує невдалі спроби.

### Commit

Очікувана конвенція повідомлення: `fix(notifications): CR-011 use configurable SMTP with TLS`.

## 5. System Test та верифікація

Запустити локально з кореня репозиторію:

```bash
python -m pip install -r requirements.txt
python -m pytest tests/ -v
python -m pytest tests/test_notify.py -v
python -m pylint src/notify.py --score=y
python -m pytest tests/ --cov=src.notify --cov-report=term-missing
git log --oneline -5
```

| Перевірка | Очікуваний критерій | Фактичний результат |
|---|---|---|
| CR вирішено | Тести `test_notify` проходять; SMTP mock підтверджує STARTTLS та send_message | Запустити локально й зафіксувати |
| Нових падінь немає | Увесь `pytest tests/ -v` успішний | Запустити локально й зафіксувати |
| Якість коду | pylint score записано; критичні помилки виправлено | Запустити локально й зафіксувати |
| Реальна доставка | У staging виконано контрольне відправлення з коректними env vars | Потрібна перевірка з доступом до SMTP |

> Unit-тести з mock не доводять доступність реального SMTP-сервера. Реальне відправлення перевіряється лише в безпечному staging-середовищі.

## 6. Acceptance / Closure та Lessons Learned

| Поле | Заповнення |
|---|---|
| Дата закриття CR | Заповнити після успішного тестування та review |
| Фактична трудомісткість | Заповнити за фактично витраченим часом |

| Що покращити наступного разу | Додати автоматичні тести SMTP-контракту, логування помилок без секретів, моніторинг черги/доставки та staging smoke-тест. |

## Додаток: безпечна конфігурація

Приклад змінних середовища для локального/staging запуску (значення задайте власні, секрети не комітьте):

```bash
export SMTP_HOST="smtp.example.com"
export SMTP_PORT="587"
export SMTP_USER="your-account@example.com"
export SMTP_PASS="your-app-password"
export SMTP_TIMEOUT="10"
```

На Windows PowerShell використовуйте `$env:SMTP_HOST = "smtp.example.com"` тощо.
