## 4. Реалізація

В `src/notify.py` заглушку замінено реалізацією SMTP через стандартну бібліотеку Python. Параметри SMTP читаються зі змінних середовища. Встановлено timeout, використовується STARTTLS із SSL-контекстом. `send_email()` повертає `False` при помилці SMTP або порожній адресі. `notify_user()` повертає результат доставки, а `bulk_notify()` рахує невдалі спроби.

## Додаток: безпечна конфігурація

Приклад змінних середовища для локального/staging запуску (значення задайте власні, секрети не комітьте):

```bash
export SMTP_HOST="smtp.example.com"
export SMTP_PORT="587"
export SMTP_USER="your-account@example.com"
export SMTP_PASS="your-app-password"
export SMTP_TIMEOUT="10"
```

На Windows PowerShell використовуйте `$env:SMTP_HOST = "smtp.example.com"` тощо.
